    Help & tips

    Using FillCraft
    ShortcutsEach mode has a keyboard shortcut; the result count shows on the toolbar icon, and the full log when you reopen this popup.
    ResultsAfter a fill, every field is listed as filled, skipped or failed — with the reason. Click a row to jump to that field. Copy report shares the run without any field values.
    StopWhile a fill runs, Stop ends it after the field it is working on. What was filled stays — use Clear form to empty it.
    Detect fieldsPreviews what each field is recognized as, using your settings. * marks required fields.
    What gets filled
    Page errorsIf the page shows an error on a field ("Enter a number between 0 and 99"), FillCraft enters a value that follows it, or clears the field and reports the message. With Invalid / Edge data it only records the message.
    Sections, tabs & uploadsCollapsed sections and tabs in the form are opened and filled. With Attach sample files on, upload fields get fake test files (Settings → Manage test files).
    Right-click a fieldRight-click any field → FillCraft: Fill this field or Fill this section (Valid / Invalid / Edge), Treat this field as… a type FillCraft got wrong, Leave this field alone, or Forget my setting. Settings are kept per website (Settings → Field settings…). The toolbar icon shows ✓ when done — point at it for details.
    Test patientSettings → Test patient: a child (with a parent or guardian), an adult or a senior on Medicare; the kind of insurance (none = self-pay, insurance boxes left empty); a state. Keep the same person fills every page of a multi-page form with one patient until you press New person. Copy report names the person only by a short number.
    PasswordsWith Valid data every password box gets the same password — Admin@1234 by default (Settings → Password for test accounts) — so anyone can sign in to the accounts created. When a form's rules refuse it (longer, shorter, "too common"), a close variant is used for that form, and its confirm box gets the same; the results list shows the password used. Test systems only.
    Boundary testingSettings → Edge cases → Field limits uses each field's maxlength, min/max. Fields with no length limit are tested at 255 / 256 characters.
    Safety
    Open dialogsWith a dialog or side panel open over the page, Fill, Clear and Detect work only inside it — never on the screen behind it. A dialog without fields ("Discard changes?") is left alone; close it to fill the page.
    Never touchedHidden bot traps, CAPTCHAs, verification codes, drawn signature pads, disabled fields and site navigation. (A typed-signature box gets the person's name; with "Attach sample files" on, a signature upload gets the sample image.) FillCraft never submits, saves, cancels or closes anything: while it works, a form submit or a click on Save / Submit / Cancel / Close / × is stopped.
    Safe dataAll data is synthetic. Phones use the fictional 555-01XX range; emails go to public mailinator.com inboxes; sample files are marked SAMPLE. FillCraft never submits a form.
    Troubleshooting
    RecognitionFields are matched by label, name, id, placeholder, aria-label, autocomplete, data-testid and the nearest heading. A dropdown not filled? Use Copy dropdown details in the results and send it to whoever maintains FillCraft.
